# מצגת AI - שיעור 2

מצגת אינטראקטיבית בעברית לעולם הבינה המלאכותית, בנויה עם Reveal.js. השיעור השני בסדרה ללימוד מושגי AI.

## תכונות

- מצגת שקפים אינטראקטיבית עם מעברים חלקים
- פריסת RTL עברית עם עיצוב מותאם
- ערכת נושא כהה עם רקעים גרדיאנטיים
- כרטיסים מונפשים ואפקטי הדגשה
- עיצוב רספונסיבי למקרנים ומסכים

## טכנולוגיות

- Reveal.js 4.3
- HTML/CSS
- Google Fonts (Rubik)

## שימוש

פתחו את `index.html` ישירות בדפדפן.
