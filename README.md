# AI Presentation - Lesson 2

An interactive Hebrew presentation exploring the world of artificial intelligence, built with Reveal.js. This is the second lesson in a series designed for teaching AI concepts.

## Features

- Interactive slide deck with smooth transitions
- Hebrew RTL layout with custom styling
- Night theme with gradient backgrounds
- Animated cards and highlight effects
- Responsive design for projectors and screens

## Tech Stack

| Technology | Purpose |
|-----------|---------|
| [Reveal.js 4.3](https://revealjs.com/) | Presentation framework |
| HTML/CSS | Structure and styling |
| Google Fonts (Rubik) | Hebrew typography |

## Usage

Open `index.html` directly in a browser, or serve it with any static file server:

```bash
# Using Python
python -m http.server 8000

# Using Bun
bunx serve .
```

Then navigate to [http://localhost:8000](http://localhost:8000).

### Navigation

- **Arrow keys** or **Space**: Navigate between slides
- **Esc**: Overview mode
- **F**: Fullscreen
- **S**: Speaker notes
